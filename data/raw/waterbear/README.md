# GSE242880 Waterbear benchmark inputs

- `GSE242880_high_low_MOI_screens_D1_D2_D3_2022-04-23.count.txt.gz`
  is the processed guide-count matrix deposited with
  [GSE242880](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE242880).
  Direct download:
  `https://ftp.ncbi.nlm.nih.gov/geo/series/GSE242nnn/GSE242880/suppl/GSE242880_high_low_MOI_screens_D1_D2_D3_2022-04-23.count.txt.gz`

  the authors'
  [Waterbear analysis repository](https://github.com/pimentel/waterbear_analysis).
  Direct download:
  `https://raw.githubusercontent.com/pimentel/waterbear_analysis/main/data/cd25_validated_targets%20revised.csv`
